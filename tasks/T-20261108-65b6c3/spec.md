# Spec: แก้ให้ ui มี text ด้วย

รหัสงาน: `T-20261108-65b6c3` อ้างอิงจาก `intent.md`

## พฤติกรรมที่ต้องมี

ข้อมูลจาก `intent.md` ยังไม่เพียงพอที่จะกำหนดพฤติกรรมเฉพาะเจาะจง สิ่งที่ยืนยันได้มีเพียงว่า UI ส่วนที่เกี่ยวข้องต้องแสดงข้อความ (text) ให้ผู้ใช้เห็น

พฤติกรรมเบื้องต้น (ใช้ได้เมื่อได้รับข้อมูลครบจากผู้ขอ):

- UI ส่วนที่ผู้ขอระบุต้องแสดงข้อความตามเนื้อหา ตำแหน่ง และรูปแบบที่ผู้ขอกำหนด
- ข้อความต้องอ่านได้ชัดเจน ไม่ทำให้เลย์เอาต์เดิมเสียหาย และไม่ล้นพื้นที่
- UI ส่วนอื่นที่ไม่เกี่ยวข้องต้องทำงานและแสดงผลเหมือนเดิม
- การเปลี่ยนแปลงจำกัดอยู่ที่การเพิ่มข้อความเท่านั้น ไม่เปลี่ยนโครงสร้าง ดีไซน์ หรือพฤติกรรมการทำงานอื่นของ UI

สิ่งที่ยังไม่รู้ (ไม่เดา):

- หน้าจอหรือคอมโพเนนต์ที่ต้องเพิ่มข้อความ
- เนื้อหาข้อความและภาษาที่ใช้
- ตำแหน่งและรูปแบบการแสดงข้อความ
- สถานะปัจจุบันของ UI ว่าแสดงอะไรอยู่ (เช่น ไอคอนอย่างเดียว ช่องว่าง หรือไม่แสดงอะไรเลย)

## กรณีขอบ

ยังระบุกรณีขอบที่เฉพาะเจาะจงไม่ได้ เพราะไม่ทราบว่า UI ส่วนใดเกี่ยวข้อง กรณีที่ควรตรวจเมื่อทราบรายละเอียดแล้ว:

- ข้อความยาวเกินพื้นที่ ต้องตัดคำ ขึ้นบรรทัดใหม่ หรือย่อ ตามที่ผู้ขอกำหนด
- ข้อความภาษาไทย (วรรณยุกต์และสระซ้อน) แสดงผลถูกต้อง ไม่ถูกตัดขอบบนหรือล่าง
- กรณีไม่มีข้อมูลหรือข้อความว่าง ต้องกำหนดว่าจะแสดงอะไรแทน
- ขนาดหน้าจอหรือขนาดตัวอักษรที่ต่างกัน ข้อความต้องไม่ทำให้เลย์เอาต์พัง
- หากระบบรองรับหลายภาษา ต้องกำหนดว่าข้อความต้องมีทุกภาษาหรือไม่

## เรื่องที่ต้องให้มนุษย์ตัดสิน

ต้องให้ผู้ขอตอบคำถามต่อไปนี้ก่อนเริ่มทำ:

1. UI หน้าจอหรือคอมโพเนนต์ใดที่ต้องเพิ่มข้อความ
2. ข้อความที่ต้องแสดงคืออะไร และใช้ภาษาใด
3. ต้องการให้ข้อความอยู่ตำแหน่งใดและมีรูปแบบอย่างไร
4. มีเกณฑ์ตรวจรับหรือภาพตัวอย่างอ้างอิงหรือไม่
5. ระบบต้องรองรับหลายภาษาหรือไม่
