# Intent: แก้ให้ ui มี text ด้วย

รหัสงาน: `T-20261108-65b6c3`

## ความต้องการที่ได้รับ

แก้ให้ ui มี text ด้วย

## ปัญหา

ผู้ขอแจ้งว่า UI ปัจจุบันยังไม่มีข้อความ (text) แสดงอยู่ แต่ข้อมูลที่ได้รับมามีเพียงประโยคเดียวคือ "แก้ให้ ui มี text ด้วย" จึงยังไม่ทราบสิ่งต่อไปนี้:

- UI ส่วนใด หน้าจอใด หรือคอมโพเนนต์ใดที่ขาดข้อความ
- ข้อความที่ต้องแสดงคืออะไร (เช่น ป้ายชื่อ ปุ่ม หัวข้อ ข้อความแจ้งเตือน) และใช้ภาษาใด
- ปัจจุบัน UI แสดงอะไรอยู่ (เช่น ไอคอนอย่างเดียว ช่องว่าง หรือไม่แสดงอะไรเลย)

## ผลลัพธ์ที่ต้องการ

ยังระบุผลลัพธ์ที่วัดได้ไม่ครบ เพราะข้อมูลไม่พอ สิ่งที่พอสรุปได้มีเพียงว่า UI ที่เกี่ยวข้องต้องแสดงข้อความ (text) ให้ผู้ใช้เห็น ส่วนตำแหน่ง เนื้อหา และภาษาของข้อความต้องรอการยืนยันจากผู้ขอ

## ขอบเขต

- เพิ่มการแสดงข้อความใน UI ส่วนที่ผู้ขอระบุ (ยังไม่ทราบว่าคือส่วนใด)
- ขอบเขตที่แน่ชัดต้องรอผู้ขอยืนยันก่อนเริ่มทำ

## สิ่งที่ไม่ทำ

เนื่องจากข้อมูลยังไม่พอ จึงกำหนดข้อจำกัดชั่วคราวดังนี้ (รอยืนยัน):

- ไม่แก้ UI ส่วนอื่นที่ผู้ขอไม่ได้ระบุ
- ไม่เปลี่ยนโครงสร้าง ดีไซน์ หรือพฤติกรรมการทำงานของ UI นอกเหนือจากการเพิ่มข้อความ
- ไม่เดาข้อความหรือคำแปลเอง

## เกณฑ์ยอมรับ

เกณฑ์ที่ตรวจได้จริงยังกำหนดไม่ได้จนกว่าจะทราบรายละเอียดเพิ่ม เกณฑ์เบื้องต้นที่ใช้ได้เมื่อได้ข้อมูลครบ:

- UI ส่วนที่ระบุแสดงข้อความตามที่ผู้ขอกำหนดอย่างถูกต้อง
- ข้อความอ่านได้ชัดเจนและไม่ทำให้เลย์เอาต์เดิมเสียหรือข้อความล้น
- ส่วนอื่นของ UI ที่ไม่เกี่ยวข้องยังทำงานและแสดงผลเหมือนเดิม

**สิ่งที่ยังไม่รู้และต้องถามผู้ขอ:**

1. UI หน้าจอหรือคอมโพเนนต์ใดที่ต้องเพิ่มข้อความ
2. ข้อความที่ต้องแสดงคืออะไร และใช้ภาษาใด
3. ต้องการให้ข้อความอยู่ตำแหน่งใดและมีรูปแบบอย่างไร
4. มีเกณฑ์ตรวจรับหรือภาพตัวอย่างอ้างอิงหรือไม่
